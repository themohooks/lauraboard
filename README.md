# Laurabrod — автоматизация вещания интернет-телеканала

Программа на Rust для Windows и Linux. Ведёт круглосуточное (24/7) вещание собственного интернет-телеканала: сетка вещания, плейлисты, заставки, реклама и анонсы по правилам, логотип и экранная графика, RTMP/SRT/HLS-выход. Есть графический интерфейс, командная строка и локальный API.

```
 сетка + плейлисты + правила ──▶ планировщик ──▶ рундаун (время каждого ролика)
                                                     │
 декодер FFmpeg на каждый ролик ──MPEG-TS──▶ энкодер FFmpeg ──▶ RTMP / SRT / UDP / HLS / запись
                         графика (Rust, RGBA) ──TCP──▶ ┘ └──▶ превью (JPEG) для GUI/API
```

## Возможности

- **Планирование эфира.** Два режима: последовательный и сетка с фиксированным временем начала. Время начала и окончания каждого элемента рассчитывается заранее. Прогноз эфира строится на часы и дни вперёд.
- **Правила вставок.** Заставки, рекламные блоки и анонсы вставляются каждые N роликов, каждые M минут, в начале или конце блока, между блоками, до или после категории. Есть условия по категориям, часам и дням недели, вероятности, приоритеты и группы. Одна и та же вставка не повторяется подряд.
- **Точное время.** Ролик не обрезается без явного разрешения. Чтобы передача началась вовремя, планировщик по очереди:
  1. убирает необязательные вставки;
  2. обрезает ролик, если это разрешено;
  3. если не помогло, сдвигает передачу и пишет предупреждение.

  Пустоты заполняются анонсами и роликами-заполнителями, остаток — заставкой-заглушкой.
- **Реклама.** Отдельные рекламные блоки (в том числе фиксированной длительности), ограничение показов в сутки, минимальный интервал повтора, ручная вставка, статистика показов.
- **Графика.** Логотипы, текстовые плашки, бегущая строка, часы, таймеры, композиции и слои, анимация появления и исчезновения. Правила показа: по времени, через N секунд после начала ролика, за N секунд до конца, по типам и категориям. Есть ручной вызов.
- **Надёжность.** После перезапуска эфир продолжается с того же ролика и места. Энкодер перезапускается автоматически с увеличивающейся паузой. Недоступные файлы пропускаются, при пустом эфире показывается резервный контент. Сторожевой таймер ловит зависшие ролики. Защита от второго экземпляра канала, журнал эфира (as-run).
- **Управление.** GUI в стиле Material 3 (Slint), CLI (`laurabrod ...`), REST + WebSocket API с токенами и ролями, служба Windows и сервис systemd.

## Быстрый старт

Требуются Rust ≥ 1.92 и FFmpeg ≥ 6.1 (`ffmpeg` и `ffprobe` в PATH).

```bash
cargo build --release
```

```bash
./target/release/laurabrod -p mytv init --demo
```

```bash
./target/release/laurabrod -p mytv plan --hours 3
```

```bash
./target/release/laurabrod -p mytv gui
```

`init --demo` создаёт демонстрационный канал: генерирует тестовые ролики, настраивает сетку с ежечасными новостями, рекламу, анонсы и графику. Выход — HLS в `mytv/output/hls/live.m3u8` (открывается в VLC или ffplay). Команда `gui` запускает движок вместе с окном управления. Чтобы работать без GUI (например, на сервере), используйте `laurabrod -p mytv run`.

## Архитектура

| Крейт | Назначение |
|---|---|
| `lb-core` | Модель данных, конфигурация, валидация, **планировщик** (без IO, покрыт тестами) |
| `lb-media` | Команды FFmpeg, ffprobe, процессы, прогресс, превью |
| `lb-gfx` | Композитор графики (tiny-skia, векторный текст) |
| `lb-engine` | Движок канала: воспроизведение, супервизия, графика, журнал, статистика |
| `lb-api` | REST + WebSocket (axum) |
| `lb-gui` | Интерфейс оператора (Slint, Material 3), работает только через API |
| `laurabrod` | Исполняемый файл: CLI, GUI, служба |

GUI и CLI не связаны с механизмом воспроизведения напрямую: они работают через API или файлы проекта. Медиадвижок отделён от планировщика: планировщик выдаёт рундаун, движок его исполняет.
