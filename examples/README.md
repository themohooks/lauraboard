# Примеры

## demo/

Конфигурация демонстрационного канала **LAURA TV**. Именно её создаёт `lauraboard init --demo`:

- **`channel.toml`** — 1280×720, 25 к/с, libx264 2,5 Мбит/с. Выход HLS в `output/hls/live.m3u8` и пример RTMP-выхода для YouTube (выключен).
- **`schedule.toml`** — сетка: новости каждый час в `HH:00`, после них дневной эфир. В 20:05 фиксированный «Вечерний кинозал». По выходным свой шаблон с перемешанным плейлистом и закреплённым первым роликом.
- **`rules.toml`**:
  - заставка перед новостями;
  - заставка каждые 2 передачи;
  - реклама каждые 20 минут (кроме новостей и фильмов), не больше 2 роликов, сначала реже показанные, с заставкой-перебивкой;
  - анонсы между блоками;
  - затемнение 300 мс.
- **`graphics.toml`**:
  - логотип и часы (не показываются во время рекламы);
  - плашка с названием и ведущим через 5 с после начала передачи;
  - «Далее: … в …» за 20 с до конца;
  - бегущая строка с переменной `{ticker}`.

Медиафайлы в репозиторий не входят. Чтобы получить работающий канал с тестовыми роликами (их генерирует FFmpeg), выполните:

```bash
lauraboard -p mytv init --demo
```

Чтобы посмотреть, как этот пример планирует эфир (ролики не нужны), сначала скопируйте его:

```bash
cp -r examples/demo mytv-config
```

Затем постройте прогноз:

```bash
lauraboard -p mytv-config plan --hours 2
```

## Режим без сетки

Для простого круглосуточного канала из одного плейлиста укажите в `channel.toml`:

```toml
[planning]
mode = "sequential"
playlist = "main"
```

Правила вставок (заставки, реклама) в этом режиме тоже работают.
