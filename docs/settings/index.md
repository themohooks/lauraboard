# Как найти нужную настройку

| Что изменить | Где открыть инструкцию | Когда применяется |
|---|---|---|
| Тема, масштаб, плотность, панели | [Интерфейс](../guides/appearance.md) | Сразу, локально |
| Уведомления и трей | [Интерфейс](../guides/appearance.md) | Сразу, локально |
| Подключение, токен и роль | [Подключение](../guides/connection.md) | При запуске клиента; токены задаёт администратор |
| Имя, идентификатор, автозапуск, аватар | [Каналы](../guides/manage-channels.md) | Через отдельные действия; идентификатор меняется при остановленном канале |
| Свойства материала, изображение и громкость | [Свойства](../guides/media-display.md) | После сохранения; проверять следующий показ |
| Видео, аудио, качество и кодирование | [Кодировщик](../guides/encoder.md) | С перезапуском кодировщика |
| Точки назначения | [Выходы](../guides/outputs.md) | Возможен перезапуск выхода |
| Запись и её хранение | [Запись](../guides/recording.md) | Отдельный процесс записи |
| Планирование и заполнение | [Сетка](../guides/schedule-timing.md), [правила](../guides/insertion-rules.md) | После сохранения и пересчёта |
| Сцены и музыка | [Сцены](../guides/scenes.md) | После сохранения, при показе сцены |
| Графика | [Оформление](../guides/graphics.md), [правила](../guides/graphics-rules.md) | После сохранения, с учётом ручных переопределений |
| FFmpeg, API, журналы, webhook, последовательный режим | [Конфигурация](../configuration.md) | По процедуре администрирования; перезапуск/перезагрузка зависит от параметра |

Значения по умолчанию подтверждены для GUI: системная тема, 100 %, обычная плотность, системные анимации, подписи навигации включены, сворачивание в трей включено при его наличии. Уведомления включены, сообщения о каждой передаче и ограничение «только скрытое окно» выключены. Для серверных значений используйте текущую конфигурацию: демонстрационный проект отличается от чистого канала.

Перед изменением записывайте прежние значения. Общего безопасного сброса всех настроек канала одной кнопкой в изученном GUI нет. Сброс GUI не сбрасывает расписание и медиа, но может потерять собственные локальные стили.
