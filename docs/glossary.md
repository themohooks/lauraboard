# Словарь оператора

| Термин | Значение |
|---|---|
| Проект | Папка с общими настройками и каналами |
| Канал | Отдельная программа вещания со своими материалами и настройками |
| Медиатека | Каталог материалов; может содержать ссылки на файлы или собственные копии |
| Плейлист | Список материалов и порядок их воспроизведения |
| Сетка | Расписание блоков |
| Шаблон дня | Набор блоков, назначаемый дням недели |
| Блок | Часть сетки с источником и ограничениями |
| Рундаун / прогноз | Рассчитанный список элементов эфира со временем |
| As-run | Фактическая история показов |
| Заставка | Короткий оформляющий ролик |
| Заполнитель | Материал для свободного промежутка |
| Сцена | Фон, музыка и графика, собираемые программой; в обзоре источников это слово также используется для расписаний |
| Правило / триггер | Условия вставки и событие, которое запускает её проверку |
| Категория | Метка материала для отбора по смыслу |
| Кодировщик | Процесс FFmpeg, формирующий выход канала |
| Битрейт | Количество данных потока за секунду |
| Контейнер | Способ упаковки видео и звука, например MP4 или MPEG-TS |
| HLS | Поток из плейлиста `.m3u8` и небольших файлов-сегментов |
| RTMP / SRT / UDP | Способы передачи потока по сети |
| API | Интерфейс команд и данных, через который GUI общается с движком |
| Токен | Секретная строка доступа к API |
| Трей | Область системных значков возле часов ОС |
| Ручной режим | Приостановка автоматического расписания для действий оператора |
| Плашка | Графическая подложка с одной или несколькими текстовыми строками |
| Переменная | Имя в фигурных скобках, заменяемое данными эфира |
