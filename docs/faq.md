# Частые вопросы

## Нужен ли аккаунт?

Обязательной регистрации в самом приложении не обнаружено. Для удалённого API может требоваться токен и роль; для внешней площадки нужны её учётные данные и ключ вещания.

## Почему ролик есть в медиатеке, но не выходит в эфир?

Добавление не создаёт расписание. Добавьте материал в плейлист/блок, проверьте включение, выбранную сетку, дату и ручной режим. [Сетка](guides/schedule.md).

## Чем сцена отличается от готового видео?

Она собирается из фона, музыкальных правил и графики в программе. Её можно ставить в плейлист как материал. В разделе источников слово «сцены» также используется для переключаемых расписаний. [Гайд](guides/scenes.md).

## Можно закрыть окно и оставить эфир?

Скрытие в трей сохраняет процесс. Явный выход при встроенном движке останавливает его; закрытие клиента отдельного сервера не завершает сервер. [Настройки](guides/appearance.md).

## Пауза расписания — это пауза видео?

Нет. Это ручной режим. Для автоматической работы нажмите **Вернуться к расписанию**. [Управление](guides/air-control.md).

## Почему вставка «в заданное время» запаздывает?

Этот триггер ждёт границы основного материала. Для фиксированного начала нужен блок сетки и согласованные ограничения. [Правила](guides/insertion-rules.md).

## Почему правило графики верное, а логотип скрыт?

Проверьте слой и ручное переопределение. Нажмите **По правилам показа**. [Гайд](guides/graphics-rules.md).

## Где звук предпросмотра?

Монитор показывает JPEG-превью. Для проверки звука используйте локальный выход или запись; движущаяся картинка не доказывает наличие аудио у получателя.

## Можно работать без интернета?

Локальным материалам и локальному выходу внешняя сеть не нужна сама по себе. API должен быть доступен; потоки, внешнее вещание и Google Fonts требуют своих подключений.

## Почему мои файлы с компьютера оператора не видит сервер?

Поле пути относится к серверу. Передайте материалы туда разрешённым способом или используйте доступное хранилище. [Импорт](guides/import-media.md).

## Экспорт M3U сохраняет видео?

Нет. Он сохраняет список и ссылки. Для канала с материалами используйте [ZIP-экспорт](guides/transfer-channel.md).

## Архив backup подходит для импорта канала?

Это разные форматы и составы. `backup` восстанавливается командой `restore`; ZIP-экспорт канала — через **Импорт из архива**. [Копии](data-and-backup.md).

## Удалённый канал можно вернуть?

При обычном удалении его папка переносится в `deleted`. При безвозвратном стирании нужна независимая копия. [Восстановление](guides/backup-restore.md).

## Почему после удаления данных исчезли собственные файлы?

Деинсталлятор может удалить весь `channels/`. Файлы внутри него удаляются вместе с папкой, даже если общий текст обещает сохранить медиа. [Удаление](update-and-uninstall.md).

## Какой компьютер нужен для нескольких каналов?

Измеренных гарантий в проекте нет. Проверьте нагрузку на своём формате, графике, источниках и записи. [Совместимость](compatibility.md).
