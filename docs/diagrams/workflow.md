# Как материалы превращаются в эфир

```mermaid
flowchart LR
    A[Медиатека] --> B[Плейлисты]
    A --> C[Сцены]
    B --> D[Сетка]
    C --> D
    E[Правила вставок] --> F[Прогноз]
    D --> F
    F --> G[Эфир]
    H[Экранная графика] --> G
    G --> I[Точки вещания]
    G --> J[Запись]
    G --> K[Факт эфира и статистика]
```

Прогноз показывает намерение планировщика; факт эфира фиксирует выполненные показы. Ручное управление может изменить выполнение.
