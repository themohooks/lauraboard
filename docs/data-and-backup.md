# Где находятся данные и как их сохранить

Проект хранится в каталоге, который выбран при установке либо передан через `-p`. Все приведённые ниже пути относительны этому каталогу, если не сказано иначе.

| Данные | Расположение и особенности |
|---|---|
| Общие настройки и доступ API | `laurabrod.toml`; может содержать токены |
| Документы канала | `channels/<id>/`: параметры, медиатека, плейлисты, сетка, правила, графика |
| Собственные медиа | Внутри каталога канала; импорт может также ссылаться на внешние файлы |
| Состояние восстановления | `channels/<id>/state/`; не редактируйте при работающем движке |
| Факт эфира | `channels/<id>/asrun/`; используется для отчётов и истории повторов |
| Журнал приложения | По умолчанию `logs/`, меняется в глобальной конфигурации |
| HLS | Каталог из URL выхода, например `output/hls/`, от корня проекта |
| Записи | Путь из настроек записи; относительный — от папки канала |
| Удалённые каналы | `deleted/<id>-<время>/`, если не выбрано безвозвратное стирание |
| GUI Windows | `%APPDATA%/laurabrod/gui.json`, последний проект — `desktop.json` |
| GUI Linux | Каталог конфигурации пользователя, обычно `~/.config/laurabrod/`; учитывается XDG |
| Шаблоны оформления | `gfx-templates/` рядом с настройками GUI; собственные стили плашек входят в `gui.json` |

## Как выбрать способ копирования

| Задача | Способ | Чего недостаточно |
|---|---|---|
| Перенести один канал с материалами | [Экспорт канала](guides/transfer-channel.md) с нужными флажками | Не сохраняет всю установку и локальные настройки оператора |
| Быстро сохранить конфигурацию проекта | Команда [backup](guides/backup-restore.md) | Не сохраняет медиа, ресурсы, записи и всю историю |
| Сохранить всё для восстановления | Остановить движок, скопировать проект, внешние материалы, записи и GUI | Нельзя забывать файлы вне проекта |

## Как избежать потери данных

Перед удалением, обновлением и импортом проверьте копию в отдельном каталоге. Сохранение файлов не равно успешному восстановлению. Для переноса между ОС исправьте абсолютные пути и проверьте шрифты, кодеки и протоколы.

Записи с лимитами хранения удаляются автоматически. Удаление собственного материала из медиатеки может убрать его копию на диске. Удаление канала с **Стереть файлы безвозвратно** не оставляет папку `deleted`.

Деинсталлятор обычно оставляет проекты. Опция удаления данных удаляет `laurabrod.toml`, `channels/`, `logs/`, `output/` выбранного проекта. Поскольку собственные медиа, аватары и записи могут находиться **внутри `channels/`**, они также могут быть удалены. Не полагайтесь на общее обещание «медиа остаются» без проверки фактических путей.

Безопасное удаление личных данных начинается с определения всех копий, архивов и внешних файлов. Программа не предоставляет подтверждённого средства гарантированного стирания носителя.
