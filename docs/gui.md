# Интерфейс оператора

Интерфейс сделан на [Slint](https://slint.dev) в стиле Material Design 3 и работает через HTTP и WebSocket API. При подключении к отдельному серверу закрытие клиента не завершает сервер. Если движок запущен внутри GUI, явный выход завершает процесс и останавливает эфир; скрытие окна в трей сохраняет процесс. Подробнее — [закрытие окна и трей](guides/appearance.md).

Для практических задач используйте [каталог пошаговых гайдов со скриншотами](guides/index.md). Этот документ — краткий технический обзор.

```bash
lauraboard -p D:\tv gui
```

```bash
lauraboard gui --connect http://192.168.1.10:8787
```

Без `--connect` интерфейс подключается к уже работающему экземпляру (служба, `run`) или запускает встроенный движок.

### Запуск с ярлыка или двойным щелчком

Если `lauraboard` запущен без аргументов не из терминала (двойной щелчок по файлу, ярлык, меню приложений), он работает как `lauraboard gui`. Консольное окно Windows при этом закрывается. Открывается проект:

1. текущая папка, если в ней есть `lauraboard.toml`;
2. иначе последний проект, открытый в интерфейсе (`desktop.json` рядом с `gui.json`, его же записывает установщик);
3. иначе `Документы/LauraBoard` — при первом запуске там создаётся пустой проект.

Ошибки в этом режиме показываются в окне сообщения. Из терминала всё работает как раньше: без аргументов выводится справка, `gui` открывает интерфейс в текущем проекте.

| Настройки | тема, масштаб, плотность, анимации, уведомления, сброс компоновки, подключение |  |

Общие клавиши: Ctrl+S — сохранить, Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) — отменить / повторить, Ctrl+F — поиск, Delete — удалить выбранное, F5 — обновить данные, Esc — закрыть диалог.

Каналы переключаются в шапке окна; кнопка рядом открывает менеджер каналов (переименование, копия, экспорт, удаление). У канала может быть аватар: картинка выбирается в форме канала («Выбрать картинку…», из середины вырезается квадрат 256×256) и видна в шапке, в списке каналов и в уведомлениях; в экранную графику её добавляет пункт «Аватар канала».

Опасные действия (остановка эфира, удаление, переключение расписания) требуют подтверждения. Состояние всегда показывается иконкой и текстом, не только цветом.

## Настройки интерфейса

Настройки хранятся на компьютере оператора и на эфир не влияют:

- Windows: `%APPDATA%\lauraboard\gui.json`
- Linux: `~/.config/lauraboard/gui.json`

Сохраняются тема (системная, светлая, тёмная), масштаб 80–200 % поверх масштаба экрана ОС, компактная плотность, анимации (как в системе, включены, выключены), последний раздел, ширина панелей и вид медиатеки. «Как в системе» для анимаций читает «Показывать анимацию» в Windows и `org.gnome.desktop.interface enable-animations` в GNOME.

При ширине окна меньше 1200 пикселей навигация сворачивается в узкую панель, а экраны переходят в компактную раскладку: вкладки уходят под заголовок, список и форма правил показываются по очереди. Минимальный размер окна — 960×600.

Шаблоны оформления графики сохраняются рядом с настройками, в папке `gfx-templates`.

## Уведомления

Интерфейс показывает собственные всплывающие уведомления — карточки в правом нижнем углу экрана (на macOS — в правом верхнем) с аватаром канала, заголовком, текстом и временем; они видны поверх других окон, и когда программа свёрнута в трей, и не забирают фокус у окна, в котором вы работаете. Карточка закрывается сама через 7 секунд (важные — через 20), не исчезает, пока над ней указатель, закрывается крестиком, а щелчок по ней открывает окно программы; одновременно видно до четырёх карточек. Уведомляется: остановка и восстановление кодировщика, потеря связи с сервером, пропущенные ролики, недоступные точки вещания, мало места на диске для записи (меньше 5 ГБ), запуск и остановка эфира, ручной режим; по желанию — каждая новая передача. Что показывать, выбирается в «Настройки → Уведомления», там же кнопка проверки. Одинаковое уведомление не повторяется чаще раза в минуту.

## Отрисовка

По умолчанию Slint рисует через OpenGL (FemtoVG). Если окно не открывается или рисуется с артефактами (виртуальные машины, RDP, старые драйверы), включите программную отрисовку:

```bash
SLINT_BACKEND=winit-software lauraboard gui
```

В PowerShell:

```powershell
$env:SLINT_BACKEND = "winit-software"; lauraboard gui
```

Масштаб экрана берётся из ОС. Переопределить его целиком можно переменной `SLINT_SCALE_FACTOR` (например, `1.5`), но обычно достаточно ползунка «Масштаб» в настройках.

## Linux

Для сборки нужны заголовки fontconfig, xkbcommon, Wayland и OpenGL (см. [install.md](install.md)). Окно работает и в X11, и в Wayland. Диалоги выбора файлов (импорт, экспорт CSV) используют xdg-desktop-portal: он есть в GNOME, KDE и большинстве окружений рабочего стола.

## Сторонние материалы

Иконки — Material Symbols Rounded (Apache 2.0), шрифты — Roboto и Roboto Mono (SIL Open Font License), лицензии лежат рядом с файлами в `crates/lb-gui/assets/`. Интерфейс построен на Slint (лицензия Royalty-free для настольных приложений; атрибуция — в разделе «Настройки → О программе»).
