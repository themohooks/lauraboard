# Интерфейс оператора

Интерфейс сделан на [Slint](https://slint.dev) в стиле Material Design 3. Он — отдельный клиент API: всё, что он делает, идёт через HTTP и WebSocket. Поэтому закрытие, перезапуск или зависание окна не влияет на эфир, а одним интерфейсом можно управлять удалённым сервером.

```bash
laurabrod -p D:\tv gui
```

```bash
laurabrod gui --connect http://192.168.1.10:8787
```

Без `--connect` интерфейс подключается к уже работающему экземпляру (служба, `run`) или запускает встроенный движок.

### Запуск с ярлыка или двойным щелчком

Если `laurabrod` запущен без аргументов не из терминала (двойной щелчок по файлу, ярлык, меню приложений), он работает как `laurabrod gui`. Консольное окно Windows при этом закрывается. Открывается проект:

1. текущая папка, если в ней есть `laurabrod.toml`;
2. иначе последний проект, открытый в интерфейсе (`desktop.json` рядом с `gui.json`, его же записывает установщик);
3. иначе `Документы/Laurabrod` — при первом запуске там создаётся пустой проект.

Ошибки в этом режиме показываются в окне сообщения. Из терминала всё работает как раньше: без аргументов выводится справка, `gui` открывает интерфейс в текущем проекте.

| Сетка вещания | таймлайн дня с масштабом, пустотами, конфликтами и фактом эфира; обзор нескольких суток; шаблоны дней | Ctrl+5 |
| Заставки и переходы | правила вставки заставок (ролики выбираются из медиатеки), мастер, проверка на прогнозе, журнал срабатываний; переходы | Ctrl+6 |
| Реклама и анонсы | правила, визуальный редактор рекламных блоков, политики | Ctrl+7 |

| Статистика | «Эфир»: период, сводка, таблицы рекламы, анонсов и всех роликов, экспорт CSV; «Система»: процессор, память, диски, сеть, процессы Laurabrod и FFmpeg | Ctrl+0 |
| Журнал событий | события эфира в реальном времени и файл журнала сервера, фильтр уровней, поиск, пауза, сохранение | |
| Настройки | тема, масштаб, плотность, анимации, системные уведомления, сброс компоновки, подключение | |

Общие клавиши: Ctrl+S — сохранить, Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) — отменить / повторить, Ctrl+F — поиск, Delete — удалить выбранное, F5 — обновить данные, Esc — закрыть диалог.

Опасные действия (остановка эфира, удаление, переключение расписания) требуют подтверждения. Состояние всегда показывается иконкой и текстом, не только цветом.

## Настройки интерфейса

Настройки хранятся на компьютере оператора и на эфир не влияют:

- Windows: `%APPDATA%\laurabrod\gui.json`
- Linux: `~/.config/laurabrod/gui.json`

Сохраняются тема (системная, светлая, тёмная), масштаб 80–200 % поверх масштаба экрана ОС, компактная плотность, анимации (как в системе, включены, выключены), последний раздел, ширина панелей и вид медиатеки. «Как в системе» для анимаций читает «Показывать анимацию» в Windows и `org.gnome.desktop.interface enable-animations` в GNOME.

При ширине окна меньше 1200 пикселей навигация сворачивается в узкую панель, а экраны переходят в компактную раскладку: вкладки уходят под заголовок, список и форма правил показываются по очереди. Минимальный размер окна — 960×600.

Шаблоны оформления графики сохраняются рядом с настройками, в папке `gfx-templates`.

## Уведомления

Интерфейс показывает системные уведомления (центр уведомлений Windows, уведомления рабочего стола Linux, macOS) — и когда окно свёрнуто в трей: остановка и восстановление кодировщика, потеря связи с сервером, пропущенные ролики, недоступные точки вещания, мало места на диске для записи (меньше 5 ГБ), запуск и остановка эфира, ручной режим; по желанию — каждая новая передача. Что показывать, выбирается в «Настройки → Уведомления», там же кнопка проверки. Одинаковое уведомление не повторяется чаще раза в минуту.

## Отрисовка

По умолчанию Slint рисует через OpenGL (FemtoVG). Если окно не открывается или рисуется с артефактами (виртуальные машины, RDP, старые драйверы), включите программную отрисовку:

```bash
SLINT_BACKEND=winit-software laurabrod gui
```

В PowerShell:

```powershell
$env:SLINT_BACKEND = "winit-software"; laurabrod gui
```

Масштаб экрана берётся из ОС. Переопределить его целиком можно переменной `SLINT_SCALE_FACTOR` (например, `1.5`), но обычно достаточно ползунка «Масштаб» в настройках.

## Linux

Для сборки нужны заголовки fontconfig, xkbcommon, Wayland и OpenGL (см. [install.md](install.md)). Окно работает и в X11, и в Wayland. Диалоги выбора файлов (импорт, экспорт CSV) используют xdg-desktop-portal: он есть в GNOME, KDE и большинстве окружений рабочего стола.
