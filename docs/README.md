# Документация LauraBoard

Для первого знакомства: [объяснение основ](start-here.md) и [учебное занятие целиком](guides/first-channel-workshop.md).

Начните с [главной страницы](index.md) или [каталога пошаговых гайдов](guides/index.md). При сбое откройте [каталог неполадок](troubleshooting/index.md).

Документы относятся к LauraBoard 0.1.0, исходной ревизии `553a617`; дата фактических проверок — 26.10.2026. [Отчёт](verification.md) различает проверку кодом, действия через API и непроверенные сценарии.

Просмотр: GitHub/GitLab либо редактор Markdown. Основные инструкции работают без генератора сайта; для схем нужен просмотрщик с Mermaid. Все переходы и изображения имеют относительные пути.

`guides/` содержит практические задачи, `troubleshooting/` — диагностику, `screenshots/` — снимки интерфейса, `diagrams/` — схемы. [Происхождение изображений](screenshots/README.md). Технические справочники CLI, API, конфигурации и служб сохранены отдельно.

[Таблица покрытия](coverage.md) связывает функции с гайдами и снимками. [CHANGELOG](CHANGELOG.md) содержит только фактические изменения документации.

[Реальное использование изображений](image-usage.md) учитывает только кадры, встроенные в инструкции, без ссылок каталога.
