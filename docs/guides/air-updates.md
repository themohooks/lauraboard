# Правила эфира, графика и HTML / SWF

## Вставка в конце каждого часа

В правилах сцен или заставок выберите **Когда → Каждый час**. Для вставки в 10:59:00, 11:59:00 и далее укажите минуту `59` и секунду `0`.

- Выключенный переключатель **Точное время важнее: обрезать текущий ролик**: ролик, заканчивающийся в 10:59:36, доиграет, затем начнётся сцена.
- Включённый переключатель: ролик обрезается в 10:59:00, затем начинается сцена. Это явное разрешение на обрезку независимо от настройки блока. Пустой источник вставки и вероятность 0 % ролик не обрезают.

Для отдельных моментов дня выберите **В заданное время** и перечислите время в формате `10:59:00, 18:59:00`. Приоритет и группа по-прежнему определяют выбор между одновременно срабатывающими правилами. Сохраните правила и проверьте их на плане.

## Начало и конец эфира

Триггеры **В начале эфира** и **В конце эфира** доступны для заставок и сцен. Они вызываются при запуске и обычной остановке вещания, а не на каждой границе блока или пересчёте плана. После команды остановки закрывающие вставки доигрывают, затем выход отключается. Завершение процесса и аварийное выключение не ожидают закрывающую вставку. При восстановлении прерванного ролика после аварии открывающая вставка не повторяется.

Для этих событий оставляйте фильтры по текущему ролику и блоку пустыми: в момент события текущая передача не является контекстом правила. Ограничения по времени и дням недели применяются.

## Логотип только на передачах

1. Добавьте логотип в **Экранная графика → Холст**.
2. В его анимации задайте появление и исчезновение **Растворение**, например 500 мс.
3. Во вкладке **Правила** создайте правило, выберите логотип и тип **Передачи**. Не выбирайте рекламу и заставки.
4. Сохраните графику. В эфире нажмите **По правилам**, если раньше включали ручной показ.

Логотип плавно скрывается при переходе на рекламу или заставку и появляется на передаче. Между соседними подходящими передачами анимация появления не повторяется. Можно дополнительно задать категории, конкретные ролики и исключения, блоки или плейлисты. Идентификаторы перечисляются через запятую; заполненные фильтры действуют одновременно. ID ролика виден в информации по нажатию на него в очереди эфира.

## Плашка через 10 секунд на 8 секунд

Создайте плашку на холсте. В новом правиле выберите её, укажите **Через (от начала)** `00:00:10` и **Показывать** `00:00:08`. Ограничьте типами или категориями нужных передач. Для периодического повтора заполните **Каждые**; для показа перед завершением ролика используйте **Последние**. Пустой текст правила оставляет текст дизайна; переменные вроде `{title}` подставляются из эфира.

## Прогресс ролика или блока / плейлиста

Выберите прогрессбар на холсте и в поле **Показывает** укажите **Ход текущего ролика** или **Ход блока / плейлиста**. В режиме сетки второй вариант считает текущий блок, в последовательном режиме — текущий проход плейлиста. **Не считать в передаче** исключает отмеченные типы вставок из общей длительности.

## HTML и SWF в графике и сценах

Выберите **Добавить → HTML / SWF анимация**, укажите файл `.html`, `.htm` или `.swf`, ширину и высоту области. Создайте правило показа и сохраните. Для сцены откройте **Редактировать графику сцены** и добавьте источник там; правило без ограничений покажет его на протяжении сцены. Для полноэкранной анимации задайте размер кадра канала и координаты 0, 0.

HTML выполняется в отдельном скрытом Edge / Chrome / Chromium. Кадры с прозрачностью передаются в обычный композитор; медленный браузер не блокирует поток эфира. CSS, JavaScript и соседние ресурсы внутри папки HTML поддерживаются. Звук браузерного источника отключён; для сцен музыка задаётся отдельно.

На Windows браузер обнаруживается автоматически. На сервере можно указать путь к исполняемому файлу в переменной окружения `LAURABOARD_BROWSER` до запуска LauraBoard.

SWF запускается через [Ruffle](https://ruffle.rs/downloads). По умолчанию загружается пакет Ruffle 0.5.0 из CDN, поэтому нужен интернет. Для автономной работы распакуйте self-hosted пакет в `assets/ruffle` рядом с исполняемым файлом либо укажите папку с `ruffle.js`, JS-модулями и WASM в `LAURABOARD_RUFFLE`. Совместимость конкретного SWF зависит от поддержки его возможностей в Ruffle. Для HTML, рисующего собственный непрозрачный фон, прозрачность нужно задать в самом документе.

Кнопка рендера редактора показывает ошибки запуска браузера или загрузки источника. Снимок HTML/SWF показывает текущее состояние анимации; в эфире кадры обновляются непрерывно.
