# Все пошаговые гайды

Если вы открыли программу впервые, начните со [вводной](../start-here.md). Затем выполните [первый канал от начала до конца](first-channel-workshop.md): каждое действие связано с проверкой результата. Для готового канала есть [учебная смена оператора](operator-workshop.md).

Если не получается отдельный шаг, откройте соответствующий гайд ниже. Не начинайте весь проект заново. Все инструкции относятся к Laurabrod 0.1.0.
