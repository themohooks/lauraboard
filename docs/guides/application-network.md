# Приложение, масштаб и локальный эфир

## Статистика приложения

«Статистика → Приложение» показывает CPU, резидентную память и дисковый ввод-вывод LauraBoard вместе с дочерними процессами. Отдельно сгруппированы интерфейс и движок, декодирование, кодирование и запись, анализ медиа, загрузки и Chromium. Общая загрузка компьютера в эти цифры не подмешивается. CPU нормирован на число логических процессоров, как процент мощности компьютера.

Трафик считается по полезным данным API/WebSocket/предпросмотра, прогрессу загрузок и ответам HLS. Это не счётчик сетевого интерфейса: служебные заголовки протоколов, внешние соединения FFmpeg/Chromium не входят в измерение. Нулевой трафик здесь не означает отсутствия внешнего потока кодировщика.

## Локальный HLS / m3u8

1. Выберите канал, откройте «Настройки → Ретрансляция в локальную сеть».
2. Включите раздачу, укажите свободный порт от 1024 до 65535 и нажмите «Применить». Для каждого канала нужен отдельный порт. Изменение перезапускает кодировщик.
3. Запустите эфир. Откройте `http://IP-КОМПЬЮТЕРА:ПОРТ/index.m3u8` в VLC, другом HLS-плеере или на устройстве в той же сети. Первый сегмент появляется примерно через четыре секунды; задержка зависит от плеера.

Используется отдельный HTTP-порт, управляющий API через него недоступен. Доступ к потоку без пароля имеют устройства, которым доступен этот порт; в настройках сети/брандмауэра его следует открывать только для нужной локальной сети. HTTPS здесь не предоставляется.

Настройка хранится в `channels/<id>/channel.toml`:

```toml
[local_hls]
enabled = true
port = 8788
```

В новых, импортированных и скопированных каналах раздача по умолчанию выключена. Временные плейлисты и сегменты хранятся в `channels/<id>/runtime/hls`; конфигурация, исходные медиа и ключи вещания не раздаются.

## Настроечные таблицы

В «Фоны → Картинки → Настроечные таблицы» по умолчанию находятся две PNG-картинки 1920×1080: цветовые полосы со шкалами яркости и таблица геометрии с сеткой, кругом и участками проверки разрешения. Цвета и геометрия рассчитываются программно, без JPEG-сжатия. Это вспомогательные таблицы, а не сертифицированный измерительный сигнал SMPTE/EBU.

Исходные файлы: `crates/lb-engine/assets/backgrounds/stills/maintenance/`. Генератор: `.github/scripts/generate_test_cards.py`. При обновлении они добавляются в существующие каналы без замены пользовательских медиа.

## Масштаб и формы

Масштаб интерфейса умножается на DPI экрана, но не заменяет его. Размер области интерфейса пересчитывается из фактического размера окна; возврат на 100% восстанавливает исходный масштаб. В небольшом окне большие страницы и диалоги прокручиваются внутри программы.

В формах каналов, импорта каналов и создания плейлистов сначала вводится название. Идентификатор формируется из него, включая транслитерацию кириллицы; после ручного изменения идентификатора название больше его не перезаписывает. Категории выбираются из списков, включая множественный выбор; новую категорию можно добавить по названию.
