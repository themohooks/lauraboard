# Как добавить логотип, текст, часы и бегущую строку

> Laurabrod 0.1.0. Снимки показывают реальный интерфейс; демонстрационные состояния подписаны отдельно. Способы и пределы проверки перечислены в [отчёте](../verification.md).

**Потребуется:** выбранный канал, для изображения — файл на компьютере оператора. Изменения оформления сначала проверяйте на учебном эфире.

## Как добавить логотип

1. Откройте **Экранная графика → Холст**.
2. Нажмите **Добавить → Изображение**.
3. Выберите новый элемент в слоях, задайте **Название**, например `Логотип`.
4. В **Содержимое → Файл изображения → Обзор…** выберите картинку. Для уже установленного аватара можно сразу выбрать **Добавить → Аватар канала**.
5. В **Положение** задайте X, Y, ширину, высоту, прозрачность и слой. Либо переместите элемент на холсте.
6. Включите безопасную зону и привязку, чтобы не разместить изображение вплотную к краю.
7. Нажмите **Сохранить**. Для ручной проверки используйте **Показать в эфире**; затем **По правилам показа**, чтобы вернуть автоматическое управление.

![Холст графики](../screenshots/interface/graphics-light.png)

Слева — слои, в центре — холст, справа — свойства выбранного элемента. Видимость на холсте и видимость в эфире — разные состояния.

## Как добавить другие элементы

1. Откройте **Добавить** и выберите тип из таблицы.
2. Заполните содержимое и оформление, разместите на холсте.
3. Сохраните и задайте [правило показа](graphics-rules.md) либо включите вручную.

| Элемент | Что настроить |
|---|---|
| Текст | Текст или `{переменные}`, шрифт и оформление |
| Бегущая строка | Текст, скорость в px/с и ширину полосы; для оператора удобно `{ticker}` |
| Часы | Формат времени, шрифт, расположение |
| Таймер | Отсчёт до конца ролика, следующей передачи или конца передачи; префикс и формат |
| До конца передачи | Отсчёт по блоку сетки с исключением отмеченных типов вставок |
| Прогресс передачи | Ход передачи или ролика, направление заполнения, размер и цвета полосы |
| Фигура | Размер, цвет, скругление и расширенное оформление |
| Плашка с текстом | Строки и подложку; [отдельный гайд](graphics-plates.md) |

Для таймера и прогресса **Не считать в передаче** исключает, например, рекламные вставки из вычисления. Передача здесь — блок сетки; при отсутствии соответствующего контекста не ожидайте корректного отсчёта всей передачи.

## Как организовать слои и анимации

1. В **Слои** создайте слой, переименуйте его и переместите элементы.
2. **Слой выше/ниже** меняет порядок наложения. **Показывать в слое только один элемент за раз** оставляет элемент с высшим приоритетом.
3. Выключение слоя в эфире запрещает автоматический показ его элементов. Значок глаза рядом с элементом скрывает его на холсте; замок блокирует перемещение.
4. Фильтры **Все / Общие / Сцены** помогают найти оформление нужного контекста. **Разложить по слоям** группирует по типам.
5. В **Анимация** выберите **Появление**, **Исчезновение**, **Длительность, мс**. Кнопка предпросмотра показывает появление на холсте.

Дублирование и удаление работают с выбранным элементом. Ctrl+Z и **Сбросить** доступны для черновика. Если логотип отсутствует в эфире, проверьте сохранение, слой, правило и ручное переопределение — [диагностика графики](../troubleshooting/broadcast.md).
