# Как подключиться к серверу и разобраться с правами

> Laurabrod 0.1.0. Снимки показывают реальный интерфейс; демонстрационные состояния подписаны отдельно. Способы и пределы проверки перечислены в [отчёте](../verification.md).

**Цель:** управлять отдельным экземпляром Laurabrod. Для обычного первого запуска с ярлыка ввод серверного адреса не требуется.

## Как проверить текущее подключение

1. Откройте **Настройки → Подключение**.
2. Проверьте **Связь есть / Нет связи**, **Сервер API**, **Каналы** и **Версия сервера**.
3. Уточните у администратора, к какому компьютеру относится этот адрес. Пути медиа и архивов при удалённой работе относятся к серверу.

![Подключение](../screenshots/interface/settings-light.png)

Карточка подключения находится ниже настроек оформления и уведомлений; прокрутите страницу. Она показывает факты подключения, а не форму редактирования адреса.

![Сведения подключения](../screenshots/parts/settings-connection.png)

Карточка показана целиком. Общая фраза внутри неё не учитывает встроенный движок: правила закрытия уточнены в [гайде интерфейса](appearance.md).

## Как открыть GUI для другого сервера

1. Получите от администратора адрес и нужный токен. Не публикуйте их.
2. В терминале запустите установленную программу с каталогом действительного проекта:

```powershell
$env:LAURABROD_TOKEN = "<ваш токен>"
laurabrod -p "D:/TV/OperatorProject" gui --connect "http://<адрес-сервера>:8787"
Remove-Item Env:LAURABROD_TOKEN
```

3. Проверьте сервер и каналы в **Настройках**. Если приложение уже открыто для того же сервера, программа может активировать существующее окно.

Каталог проекта нужен текущей команде GUI даже при явном `--connect`; пустая произвольная папка не подходит. Если токены сервером не настроены, локальное loopback-подключение получает admin, а удалённое отклоняется.

## Какие права нужны

| Роль | Возможности |
|---|---|
| viewer | Чтение состояния, прогноза, журналов и отчётов |
| operator | Управление эфиром, медиатекой, плейлистами, правилами и оформлением |
| admin | Также параметры канала, управление каналами, архивы, ключи и административные действия |

Права проверяет сервер; наличие видимой кнопки не означает разрешения выполнить запрос. При **401** проверьте токен, при **403** запросите нужную роль. Изменение конфигурации токенов поручите администратору: [справочник](../configuration.md).

Не публикуйте API без настройки доступа; обычный HTTP сам по себе не шифрует соединение. Безопасность внешнего размещения — задача администратора. Подробнее: [конфиденциальность](../privacy-and-security.md).
