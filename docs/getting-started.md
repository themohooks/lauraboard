# Быстрый старт: посмотреть готовый учебный канал

Для своего канала без терминала начните с [создания канала](guides/create-channel.md). Этот путь нужен, если вы хотите сначала увидеть готовую сетку, правила и графику.

**Потребуется:** установленная команда `lauraboard`, FFmpeg/ffprobe и новая отдельная папка. Команда демо создаёт тестовые видео и может работать несколько минут.

1. Откройте PowerShell. Создайте демонстрационный проект в новой папке:

```powershell
lauraboard -p "D:/TV/LauraBoardDemo" init --demo
lauraboard -p "D:/TV/LauraBoardDemo" validate
lauraboard -p "D:/TV/LauraBoardDemo" plan --hours 1
lauraboard -p "D:/TV/LauraBoardDemo" gui
```

2. На **Главной** проверьте состояние канала и кодировщика, затем откройте **Эфир**. Демо настроено на автозапуск и локальный HLS; пример внешней точки выключен. Перед применением иных конфигураций проверяйте выходы.
3. Найдите `output/hls/live.m3u8` в папке проекта и откройте установленным проигрывателем HLS.
4. Сравните очередь **Эфира** с **Сеткой вещания**; изучите **Заставки и переходы**, **Реклама и анонсы**, **Экранная графика**.
5. Завершите опыт кнопкой **Остановить**. Для дальнейшего знакомства можно оставить проект и медиа.

![Учебный канал](screenshots/interface/home-light.png)

На снимке — приложение с реальными тестовыми материалами. Текущие названия, часы и порядок у вас могут отличаться.

Для серверного запуска без GUI используется `run`; он работает до Ctrl+C или остановки службы. Путь `D:/TV/LauraBoardDemo` — пример, замените его доступным новым каталогом своей системы. Для Linux команды те же, но путь и имя исполняемого файла соответствуют системе.

Если `validate` сообщил об ошибке, исправьте её до запуска: [неполадки](troubleshooting/index.md). Подробные команды — [CLI](cli.md).
