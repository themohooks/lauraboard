# Как устранить проблемы с материалами

## Файлы не находятся или импорт пуст

**Сообщения:** `file not found: …`, `media file not found`, `no media files found`; GUI: **Файл ролика не найден на диске**, **Медиафайлы не найдены**.

1. В **Медиатеке** снимите фильтры и выполните **Проверить файлы**.
2. Откройте свойства проблемного материала, выпишите путь.
3. Проверьте существование файла именно на сервере вещания. Для относительного пути учитывайте корень проекта; папка оператора не является папкой сервера.
4. Если использовалась ссылка без копирования, верните исходный файл на место либо заново импортируйте доступный файл и замените ссылки в плейлистах/сетке.
5. Для папки импорта проверьте **Включая вложенные папки**, права чтения, поддерживаемый формат и ffprobe.
6. Ожидаемый результат: проверка не сообщает об отсутствующем файле, материал воспроизводится в тестовом эфире.

## Файл есть, но не читается

**Сообщения проверки:** `file is empty: …`, `file could not be decoded: …`.

Проверьте, завершилось ли копирование и ненулевой ли размер. Откройте исходник проигрывателем, проверьте FFmpeg/ffprobe. Повторно скопируйте из сохранённого оригинала. Не удаляйте единственную копию и не обещайте восстановление повреждённого видео без источника.

## Материал не удаляется

**Сообщение:** `media '<id>' is used in playlists: …` / **Ролик «…» используется в плейлистах: …**.

1. Откройте перечисленные плейлисты, удалите или замените запись, сохраните каждый список.
2. Проверьте также сетку, правила, сцены и графику, которые могли ссылаться на материал.
3. Сохраните нужную собственную копию отдельно: удаление записи медиатеки может удалить её файл из хранилища канала.
4. Повторите удаление только после проверки ссылок.

## Нет миниатюры или предпросмотра

**Сообщения:** **Кадра предпросмотра пока нет**, **Для потоков миниатюр нет**, **В этом файле нет видео**, **Не удалось получить кадр из файла**.

Для потока отсутствие миниатюры предусмотрено. Для аудиофайла нет видеокадра. Для обычного видео дождитесь рендера, проверьте файл и ffmpeg. Отсутствие миниатюры само по себе не доказывает, что звук не воспроизводится.

## Ролик нельзя перемотать

**Сообщение:** **Этот элемент нельзя перемотать (поток, картинка или заглушка)**.

Это ограничение выбранного элемента. Дождитесь локального видеоролика либо выберите его на учебном канале. При **Не удалось продолжить ролик с новой позиции — эфир перешёл к следующему элементу** проверьте декодирование исходного файла и журнал.

## Музыкальная сцена идёт в тишине

Проверьте сохранение сцены, первое подходящее музыкальное правило, включение треков, папку/категорию, дни и часы, громкость, задержку начала и паузы. Исходный звук фонового видео не используется как музыка. [Настроить музыку](../guides/scenes.md).
