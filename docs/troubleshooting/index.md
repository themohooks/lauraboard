# Найти проблему по симптому или сообщению

Начните с выбранного канала, состояния связи и времени ошибки. Не переустанавливайте программу и не удаляйте состояние до проверки причины и резервной копии.

| Симптом / фрагмент сообщения | Инструкция |
|---|---|
| Окно не открывается, артефакты, зависание запуска | [Запуск](startup.md) |
| FFmpeg не найден, `ffmpeg not found` | [Запуск](startup.md) |
| «Нет связи с сервером», неверный токен, недостаточно прав | [Связь и права](startup.md#как-восстановить-связь-и-доступ) |
| «Канал … уже запущен в другом процессе» | [Второй экземпляр](startup.md#канал-уже-запущен-в-другом-процессе) |
| Нет материалов, `file not found`, `no media files found` | [Медиа](media.md) |
| «Ролик … используется в плейлистах» | [Удаление материала](media.md#материал-не-удаляется) |
| Нет миниатюры, нельзя перемотать | [Медиа](media.md) |
| Эфир пустой, есть заглушка, нет сетки | [Эфир и расписание](broadcast.md) |
| Вставки, реклама или сцены не появляются | [Правила](broadcast.md#правило-не-срабатывает) |
| Логотип или плашка не видны | [Графика](broadcast.md#графика-не-видна-в-эфире) |
| Нет приёма у площадки, `output … unreachable` | [Выход и кодировщик](broadcast.md#выход-не-подключается-или-кодировщик-перезапускается) |
| «Не сохранено — проверка канала нашла ошибки» | [Ошибки значений](broadcast.md#настройки-не-сохраняются) |
| Нет записи, мало места | [Файлы и запись](data.md) |
| Неверный архив, `no manifest.json`, формат новее | [Архивы](data.md#архив-не-импортируется) |
| `exists (use --force to overwrite)` | [Восстановление](data.md#восстановление-конфигурации-остановилось-на-существующем-файле) |
| Неизвестная ошибка или повторный сбой | [Сбор диагностики](../support.md) |

Сообщения CLI и сервера могут быть английскими, а GUI переводит известные варианты. Полный текст FFmpeg зависит от его версии и источника; здесь не заявляется исчерпывающая база всех возможных ошибок.
