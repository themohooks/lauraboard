# Совместимость и требования

Документация относится к версии 0.1.0. В исходниках и релизной упаковке предусмотрены Windows, Linux и [macOS](macos.md). Для macOS добавлены нативные GUI/серверные сборки Intel и Apple Silicon; подтверждение нативного запуска выполняется macOS CI. Локальные проверки текущих изменений выполнены на Windows.

| Компонент | Установленные сведения |
|---|---|
| Практическая среда | Windows, FFmpeg/ffprobe 9.0.2, программный H.264 libx264, локальный HLS, MP4 H.264/AAC |
| Сборка из исходников | В манифесте Rust ≥ 1.92; проверка документации выполнялась с Rust 1.96.0 |
| FFmpeg | В существующем проекте заявлена версия ≥ 6.1; используются дополнительные возможности, в том числе `s302m` и `readrate_initial_burst` |
| GUI | Slint; стандартная графическая отрисовка либо программная, [переключение](troubleshooting/startup.md) |
| Linux GUI | X11/Wayland и системные библиотеки; для файловых диалогов используется портал рабочего стола; запуск не проверен |
| Медиа и сеть | Поддержка форматов, кодеков и протоколов зависит от конкретного FFmpeg, источника и получателя |
| Железо | Проверенных минимальных и рекомендуемых CPU/RAM/диска и количественных оценок каналов нет |

Не используйте прежние оценки вроде «столько-то ядер на канал» как гарантию. Проверьте [нагрузку](guides/statistics.md) на своём наборе материалов, частоте, разрешении, графике, записи и числе каналов. Аппаратный кодек требует работающего устройства и драйвера, а не только наличия имени в списке.

При потере интернета локальные материалы и локальный выход не требуют внешнего доступа сами по себе. Сетевые входы, внешние точки вещания, Google Fonts и настроенные сетевые уведомления зависят от соединения. Полноценный режим GUI без связи с API не предусмотрен: интерфейс должен достичь локального или удалённого движка.

Настройки времени и расписания используют локальное время сервера. Проверьте часы и часовой пояс сервера перед планированием; поведение при переводе часов отдельно не проверено.
