# LauraBoard: руководства оператора

LauraBoard автоматизирует вещание интернет-телеканала: собирает эфир из материалов, плейлистов, расписаний, правил вставок и графики. Здесь — инструкции для человека, впервые открывшего программу.

**Версия:** 0.1.0. **Исходный код:** ревизия `553a617`. **Дата проверки:** 26 октября 2026 года. Практические проверки выполнены на Windows; Linux изучен по коду. [Что именно проверено](verification.md).
